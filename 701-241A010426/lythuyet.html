PHẦN I: TRẢ LỜI CÂU HỎI LÝ THUYẾT (40 ĐIỂM)

Câu 1 (10 điểm): Phân biệt position absolute & relative trong CSS

1. Phân biệt:

  • position: relative: Dịch chuyển phần tử so với vị trí gốc của nó. Khoảng trống gốc vẫn giữ nguyên trên luồng tài liệu. Thường được gán cho khung cha để làm gốc tọa độ.
  • position: absolute: Định vị phần tử theo khung cha gần nhất có position khác static. Phần tử bị tách khỏi luồng tài liệu (không chiếm khoảng trống).

2. Ví dụ Layout Responsive (Badge sản phẩm):

.product-card {
    position: relative; /* Làm gốc tọa độ */
    width: 100%;
    max-width: 300px;
}
.badge-sale {
    position: absolute; /* Cố định góc trên bên phải */
    top: 10px;
    right: 10px;
    background: red;
    color: white;
}

3. Ảnh hưởng khi Deploy Hosting: Khi lạm dụng absolute với kích thước pixel cố định cho layout chính, giao diện sẽ bị đè chữ hoặc vỡ khung trên thiết bị di động. Cần kết hợp Flexbox/Grid cho khung tổng và chỉ dùng absolute cho chi tiết trang trí nhỏ.

Câu 2 (10 điểm): Quy trình đăng ký Domain, Hosting, DNS & Bảo mật

1. Quy trình thiết lập: Mua/đăng ký Tên miền (Domain) và Hosting → Trỏ DNS Record (A Record gán IP hosting hoặc CNAME) → Upload mã nguồn lên server via FTP/FileZilla hoặc Git.

2. Vai trò DNS: Hệ thống phân giải tên miền (DNS) chuyển đổi tên miền dạng chữ dễ nhớ (ví dụ: coffehqb.freedev.app) thành địa chỉ IP số của server hosting.

3. 2 Công cụ Serverless Deployment: GitHub Pages và Netlify (hoặc InfinityFree) hỗ trợ deploy trực tiếp từ kho mã nguồn miễn phí.

4. Rủi ro bảo mật: Nếu không cấu hình HTTPS (chứng chỉ SSL), dữ liệu truyền tải sẽ bị chặn bắt (man-in-the-middle). Không ẩn file môi trường (.env) dễ làm lộ API key hoặc FTP credentials.

Câu 3 (10 điểm): So sánh let, const, var; Hoisting và Debugging

1. Bảng so sánh:

Đặc tính var let const
Scope Function Scope Block Scope {} Block Scope {}
Hoisting Có (khởi tạo undefined) Có (nằm trong TDZ) Có (nằm trong TDZ)
Gán lại giá trị Có Có Không

2. Minh họa lỗi sai biến var trong vòng lặp bất đồng bộ:

// Lỗi dùng var: In ra 3 ba lần vì var bị nâng lên Function scope
for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log("var:", i), 100); // Kết quả: 3, 3, 3
}

// Sửa lỗi với let (Block scope tạo riêng biến i cho mỗi vòng lặp):
for (let j = 0; j < 3; j++) {
    setTimeout(() => console.log("let:", j), 100); // Kết quả: 0, 1, 2
}

3. Cách Debug bằng Chrome DevTools: Nhấn F12 → Mở tab Sources → Nhấp vào dòng code muốn đặt Breakpoint → F10/F11 để chạy từng dòng và soi giá trị biến tại bảng Scope/Watch.

Câu 4 (10 điểm): Event Delegation trong JavaScript

1. Khái niệm: Event Delegation tận dụng cơ chế Event Bubbling (sự kiện nổi bọt từ phần tử con lên cha) để gắn 1 hàm xử lý sự kiện duy nhất ở thẻ cha thay vì gán cho từng thẻ con.

2. Ví dụ xử lý danh sách động (Dynamic List):

// Thẻ cha <ul id="myList"></ul>
document.getElementById('myList').addEventListener('click', (e) => {
    if (e.target && e.target.nodeName === 'LI') {
        console.log("Đã click vào:", e.target.textContent);
    }
});

3. Lợi ích tối ưu hiệu suất: Giảm thiểu bộ nhớ RAM khi danh sách có hàng nghìn phần tử, và tự động bắt sự kiện cho các phần tử <li> mới được thêm vào qua DOM mà không cần gán lại listener.
